# SCMX-build work v0.3.0-beta.1

Private beta for repository collaborators. macOS 13 or later, Apple Silicon (arm64).

## Download and Open

1. Download `SCMX-build-work-v0.3.0-beta.1-macos-arm64.zip` from this release and extract it.
2. Open `SCMX-build-work.app` in Finder. Xcode is not required to run the app.
3. Select English or Simplified Chinese at the bottom of the sidebar. Configure the external tools needed for your workflow under Tools & Firmware Packs.

`SHA256SUMS.txt` provides the download checksum. The internal app version is 0.3.0, build 4. The app is ad-hoc signed and is not Developer ID signed or Apple notarized. Do not disable macOS security globally to open it.

## Included

- OpenOCD integration for ST-Link and CMSIS-DAP; CubeProgrammer integration for SWD, UART, and USB DFU.
- CubeMX generation, CMake builds, project import, and project-directory normalization.
- Serial terminal, OpenOCD/GDB debugging, and model-matched offline register definitions.
- Empty project, device, and firmware selections on a fresh installation. Updates retain this app's saved settings.
- English and Simplified Chinese UI and user guides.

The experimental Code Organization module is hidden from the sidebar and reorder dialog. Its implementation and tests remain in source. This does not remove project import, CMake configuration, or Organize Project.

## Validation and Limits

Automated tests cover command construction, temporary CMake projects, pseudoterminal I/O, settings, startup, register data, process handling, logs, and localization. Test details are in [VALIDATION.md](https://github.com/aili266/SCMX-build-work/blob/v0.3.0-beta.1/docs/VALIDATION.md).

- Only the Apple Silicon build has been locally validated. No Intel binary is provided in this release.
- Physical-board programming, erase, backup, option-byte reads, and live GDB debugging have not been revalidated for this beta. CubeProgrammer's real CLI responses still require testing.
- The bundled register library contains 3,822 model/base-name entries across 30 families and 215 profiles. This is definition coverage, not a tested-board list. Unknown models do not use another family's addresses.
- Multi-core or multi-security-domain profiles support offline browsing only. Register reads can affect hardware flags.
- External Flash loaders, batch programming, security provisioning, SWO/RTT, and J-Link-specific controls are not included.

External tools and ST firmware packages are not bundled. Original app code is MIT licensed; bundled register data has separate notices and licenses retained in the app. See [THIRD_PARTY_NOTICES.md](https://github.com/aili266/SCMX-build-work/blob/v0.3.0-beta.1/THIRD_PARTY_NOTICES.md).
